# Фоновое изображение

Сохрани картинку сюда под именем **`crypto-bg.jpg`**:

    frontend/assets/crypto-bg.jpg

Как только файл появится — фон сайта включится автоматически (CSS уже настроен в
`frontend/index.html`, селектор `body::before`, путь `/static/assets/crypto-bg.jpg`).

Без файла сайт остаётся с базовым тёмным фоном — ничего не ломается.

Поддерживаемое имя — именно `crypto-bg.jpg`. Если формат другой (png/webp),
переименуй в `.jpg` или поменяй путь в CSS.
